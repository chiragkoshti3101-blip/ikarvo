# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please disclose security vulnerabilities responsibly. Do not open public issues for security concerns.

Email: chiragkoshti0628@gmail.com

We will acknowledge receipt within 48 hours and provide an initial assessment within 7 business days.

## Scope

This policy covers the `chiragkoshti3101-blip/ikarvo` repository and all code deployed from it, including:
- Next.js application code under `app/`
- API routes under `app/api/`
- Supabase migrations under `supabase/migrations/`
- Build configuration (`next.config.ts`, `vercel.json`, `package.json`)

## Out of Scope

- Vulnerabilities in third-party dependencies (report via GitHub Dependabot alerts)
- Social engineering or physical security
- Issues requiring access to credentials or secrets not present in the repository

## Acknowledgments

Security researchers who responsibly disclose vulnerabilities will be acknowledged in our release notes.
